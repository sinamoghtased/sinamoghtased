## 📂 Featured Projects

- **Portfolio-Health Dashboard (T-Mobile)** - Production 3-layer system (Java 21, Spring Boot, Angular) with a rules-based scoring engine (Easy Rules, MVEL) delivering real-time RED/YELLOW/GREEN risk signals; consolidated Jira & GitLab status into one live leadership view.
  
- **T-Concierge** - T-Mobile Summer Internship Hackathon 2026: a voice and chat assistant built directly into the T-Life app that triages customer issues before a store visit, resolving simple problems (like network resets) in chat, and booking a prepped appointment with the right store rep for issues that need in-person help, eliminating the multi-hour, no-appointment waits customers face today.
  
- **Digital Twin AI Agents for 911 Network Resilience** - SMU × AT&T × AWS hackathon project: real-time data ingestion pipeline and a dispatcher console integrated with AWS Bedrock LLMs and Amazon Transcribe for AI-assisted call handling and routing.
- **Dermatology Image Classification (Self-Supervised Learning)** - PyTorch pipeline with contrastive pretraining (modified ResNet18, NT-Xent loss) benchmarked against ImageNet transfer learning, from-scratch training, and an Autoencoder+KMeans baseline on DermaMNIST (10,015 images); achieved best-in-class **AUC 0.897**, handling a 60× class imbalance with class-weighted loss and label smoothing.

- **Binary Conversion Game** - Modular MIPS assembly game with separate logic/rendering modules; efficient binary↔decimal algorithms via logical shifts and bit manipulation, plus robust input validation and real-time feedback.

- **Adaptive Façade Design (Thesis)** - Grasshopper + Python system with SQL-backed sensor-data pipelines for dynamic optimization, cutting summer heat gain by 20% and improving energy efficiency by 5%.
  
- **Interactive Drawing Machine** - Arduino-powered system with sensors, stepper motors, and motion control for children's creative engagement; 3D-modeled mechanical design for optimized motor placement.
